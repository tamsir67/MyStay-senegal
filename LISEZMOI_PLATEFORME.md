# 🇸🇳 MyStay Voyager Sénégal — Plateforme & Application Mobile

Bienvenue sur **MyStay Voyager Sénégal**, la plateforme d'écotourisme et de séjours authentiques célébrant la **Teranga sénégalaise**.

---

## 📦 Contenu de l'archive (Fichiers ZIP)

Ce projet comprend deux versions complètes et synchronisées :

1. **📱 Application Mobile Android (Kotlin & Jetpack Compose) :**
   - Située dans le dossier `app/`
   - Prête pour Android Studio, émulateur ou compilation APK/AAB
   - Design Material 3 aux couleurs du Sénégal (Ocre, Terre cuite, Or, Vert mangrove)
   - Photographies intégrées en haute résolution dans `app/src/main/res/drawable/`
   - Icône adaptative personnalisée du Baobab Teranga

2. **💻 Plateforme Web Responsive (React + Vite + TypeScript) :**
   - Située dans le dossier `web-platform/`
   - Avec galerie photos du Sénégal (`web-platform/public/images/`)
   - Moteur de recherche et filtres par région (Sine-Saloum, Gorée, Casamance, Petite Côte...)
   - Système de réservation solidaire avec calcul transparent en FCFA
   - Conseillère IA locale **Koumba** pour la culture, le wolof et les spécialités
   - Espace Hôte pour la gestion des hébergements et reversements villageois

---

## 🚀 Démarrer la Plateforme Web (Vite + React)

Dans le terminal :
```bash
cd web-platform
npm install
npm run dev
```
La plateforme sera accessible sur `http://localhost:3000`.

---

## 📱 Démarrer l'Application Mobile Android

1. Ouvrez ce projet directement dans **Android Studio**.
2. Synchronisez avec Gradle (`Sync Project with Gradle Files`).
3. Lancez sur votre émulateur ou appareil Android physique.
